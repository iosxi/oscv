oscv v@VERSION@
====================================================================

LG モニターの「明るさ」「コントラスト」「ブラックスタビライザー」を
調整する小さなツールです。

LG の OnScreen Control は必要ありません。というより、動かしていない方が
安定します (後述)。


使い方
--------------------------------------------------------------------

oscv.exe をダブルクリックするだけです。インストールは要りません。

よく使うなら、oscv.exe を右クリック →「スタート メニューにピン留めする」
または ショートカットを作ってタスクバーに置くと便利です。

  スライダーの上でホイール   1 ずつ増減します。
                             クリックもフォーカスも要りません。
                             マウスを乗せて回すだけです。

  スライダーをドラッグ       画面がその場で追従します。
                             バーの好きな位置をクリックすると
                             そこへ直接飛びます。

  弱 / 中 / 強               3 項目をまとめて適用します。

  弱 / 中 / 強 を右クリック  今の値をそのボタンに保存します。

  起動時                     oscv を起動したときの値に戻します。
                             値は自動で覚えるので、保存の操作は要りません。
                             (画面を切り替えたときは、その画面を開いた
                              ときの値になります)

  上部のバーをドラッグ       ウィンドウを移動します。位置は覚えます。

  押しピン                   常に手前に表示するかの切り替えです。
                             白く塗って斜め = 留めている (常に手前)
                             輪郭だけで真横 = 抜いている (通常)

  「画面」の番号             調整するモニターを選びます。
                             モニターが 2 つ以上のときだけ出ます。

キーボード入力や確認ダイアログはありません。


モニターが複数あるとき
--------------------------------------------------------------------

上部のバーの下に「画面」の行が出ます。番号は Windows の設定に出る
ディスプレイ番号で、ボタンの並びは左右の並びと同じです。
押すと、そのモニターの今の値を読み直して切り替わります (約 0.3 秒)。

最終値もプリセットも、モニターごとに別々に覚えます。
最後に選んでいたモニターは、次に起動したときも選ばれます。

そのモニターに無い項目は灰色になり、値が「―」になって触れなくなります。
ブラックスタビライザーは LG 固有の項目なので、LG 以外のモニターでは
こうなります。明るさとコントラストはそのまま使えます。

DDC に何も答えないモニターは、番号が灰色になって押せなくなります。
電源が落ちている、モニターの設定で DDC/CI が切ってある、変換アダプタや
KVM が DDC を通さない、といった場合です。電源を入れてからウィンドウを
クリックすると、また押せるようになります。

Windows 側で画面が増えたり減ったりしたときは、oscv を起動し直すと
ボタンの数がそろいます。


コマンドラインから使う
--------------------------------------------------------------------

  oscv.exe 1=弱 2=強

「画面番号=プリセット」の組を並べて実行すると、窓を出さずにその場で
反映して終わります。ショートカットのリンク先に書いておけば、
2 台まとめて切り替えられます。

  画面番号     Windows のディスプレイ番号
  プリセット   弱 / 中 / 強 (1 / 2 / 3 でも可)
  組の数       いくつでも。書いた順に反映します

値は普段どおり oscv.ini から画面ごとに読みます (ini は書き換えません)。
書いた値は読み返して確かめるので、1 台あたり約 0.5 秒かかります。
指定を間違えたときだけ、使い方を出します。


左上のランプ
--------------------------------------------------------------------

  緑   正常
  橙   起動直後の読み取り中
  赤   モニターと通信できていません (下の「うまくいかないとき」へ)

ウィンドウを前面に出すたびに実際の値を読み直すので、モニター本体の
ボタンで変更した場合もすぐ表示に反映されます。


設定の保存先
--------------------------------------------------------------------

oscv.exe と同じフォルダーに oscv.ini が作られ、ウィンドウ位置・
最前面設定・最後の値・プリセットが保存されます。

書き込めない場所 (Program Files など) に置いた場合は
%APPDATA%\oscv\oscv.ini に保存されます。

設定を初期化したいときは oscv.ini を削除してください。


うまくいかないとき
--------------------------------------------------------------------

ランプが赤いときは、次のどれかが原因です。

1. モニターの設定 (OSD) で DDC/CI が無効になっている
   モニター本体のボタンから設定を開き、DDC/CI を有効にしてください。

2. 別のソフトが同時にモニターを制御している
   OnScreen Control など、モニター制御ソフトを終了してください。
   モニターとの通信路は 1 本しかないため、取り合いになると失敗します。

3. 変換アダプターや KVM 切替器が通信を通していない
   この場合、ケーブルを直結にする以外の回避策はありません。

原因が分からないときは、oscv.exe と同じ場所に「debug.on」という名前の
空ファイルを作ってから起動してください。oscv-debug.log に詳しい記録が
残ります。


動作条件
--------------------------------------------------------------------

  Windows      10 / 11
  .NET         Framework 4 (Windows に最初から入っています)
  モニター     DDC/CI 対応のもの

ブラックスタビライザーは LG 独自の項目のため、LG 以外のモニターや
一部の機種では動きません。明るさとコントラストは標準の項目なので、
たいていのモニターで動きます。


アンインストール
--------------------------------------------------------------------

フォルダーごと削除してください。レジストリは使っていません。
