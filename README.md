# oscv

LG モニターの明るさ / コントラスト / ブラックスタビライザーを調整する小さい GUI。

**LG のソフトウェアを一切使わない。** OnScreen Control も、LG のサービスも不要。
Windows 標準の DDC/CI (`dxva2.dll`) でモニターと直接やり取りする。

- ウィンドウ 250 x 239 (論理px。画面が 2 つ以上あると 275)、実行ファイル 108KB、
  依存なし (.NET Framework 4)
- マウスのみで操作。キーボード入力なし、確認ダイアログなし
- ドラッグに画面がリアルタイム追従する
- モニターが複数あれば、1 台ずつ選んで別々に調整できる

## 使い方

`oscv.exe` を実行するだけ。ショートカットを作ってタスクバーに置くと楽。

| 操作 | 動作 |
|---|---|
| スライダーの上でホイール | 1 ずつ増減。**クリック不要・フォーカス不要**（ホバーだけ） |
| スライダーをドラッグ | 画面がその場で追従。トラックをクリックするとそこへ直行 |
| 弱 / 中 / 強 を左クリック | 3 要素をまとめて適用 |
| 弱 / 中 / 強 を**右クリック** | 現在値をそのプリセットに上書き保存 |
| 起動時 | その画面を開いたときの値に戻す。値は自動で入る（右クリックの保存は無し） |
| ヘッダーをドラッグ | ウィンドウ移動（位置は記憶） |
| 押しピン | 最前面固定のオン/オフ。白く塗って斜め＝固定中、輪郭だけで真横＝解除 |
| 「画面」の番号 | 調整するモニターの切り替え（モニターが 2 つ以上のときだけ出る） |

ヘッダー左の点＝状態: 緑=正常 / 橙=初期化中 / 赤=エラー。
ウィンドウを前面に出すたびに実値を読み直すので、モニター本体のボタンで変更しても追従する。

## モニターが複数あるとき

ヘッダーの下に「画面」の行が出る。番号は Windows の設定に出るディスプレイ番号で、
ボタンの並びは左右の並びと同じ。押すとそのモニターの実値を読み直して切り替わる
（約 0.3 秒）。

**最終値もプリセットも、モニターごとに別々に覚える。** 板が違えば同じ「強」でも
ちょうどいい値は違うため。最後に選んでいたモニターは次回の起動でも選ばれる。

その板が持っていない項目は沈んで触れなくなる。たとえばブラックスタビライザーは
LG 固有なので、LG 以外のモニターでは灰色になり、値が `―` になる。
明るさとコントラストはそのまま使える。

**DDC に何も答えない画面は、番号が灰色になって押せなくなる。** 電源が落ちている、
モニターの OSD で DDC/CI が切ってある、変換アダプタや KVM が DDC を通さない、
といった画面がこれにあたる（ツールチップに「応答なし」と出る）。
電源を入れてからウィンドウをクリックすれば、また押せるようになる。

Windows に画面が増減したときは、oscv を起動し直すとボタンの数がそろう。

初回や、選んでいたモニターが外れているときは、ブラックスタビライザーに応答する板
（＝ LG）を自動で選ぶ。

キーボード入力や確認ダイアログを置いていないのは意図的で、値の変更にクリックすら
要らないようにしてある（ホイールはホバーだけで効く）。スライダーはトラック中心
±13px の帯だけが反応するので、行の余白を触っても何も起きない。

## コマンドラインから使う

```
oscv.exe 1=弱 2=強
```

「画面番号=プリセット」の組を並べる。**指定があるときは窓を出さず、その場で
反映して終わる。** ショートカットやホットキーに割り当てて、2 台まとめて
切り替えるための入口。

| | |
|---|---|
| 画面番号 | Windows のディスプレイ番号 |
| プリセット | `弱` / `中` / `強`（`1` / `2` / `3` でも可） |
| 組の数 | いくつでも。書いた順に反映する |
| 終了コード | 0 = 全部反映 / 1 = 反映できなかった画面がある |

値は GUI と同じ `oscv.ini` から画面ごとに読む。ini には何も書き戻さない。
**書いた値は読み返して確かめる**（DDC はときどき黙って取りこぼすうえ、窓が
無いぶん結果が見えないため）。1 台あたり約 0.5 秒。指定を間違えたときだけ、
使い方をダイアログで出す（窓なしの exe なのでコンソールには出せない）。

ショートカットの例（プロパティの「リンク先」）:

```
C:\path\to\oscv.exe 1=強 2=中
```

## 対応環境

| | |
|---|---|
| Windows | 10 / 11 |
| .NET | Framework 4（Windows に同梱） |
| モニター | DDC/CI 対応のもの |

明るさとコントラストは標準の項目なので、たいていのモニターで動く。
ブラックスタビライザーは LG 固有の項目のため、LG 以外や一部機種では動かない。

## 設定ファイル

`oscv.ini`（exe と同じ場所。書き込めなければ `%APPDATA%\oscv\`）にウィンドウ位置・
最前面・最終値・プリセットを保存。プリセット初期値:

| | 明るさ | コントラスト | ブラックスタビライザー |
|---|---|---|---|
| 弱 | 30 | 10 | 20 |
| 中 | 40 | 40 | 16 |
| 強 | 65 | 75 | 13 |

「起動時」の値は ini に残さない。起動し直せば、その時点の実値がまた入る。

**プリセットも最終値もモニターごとに完全に分けて保存する。** ini のキーは
`m2.preset0_0` のように画面番号を頭に付ける。番号なしのキー（v3 まで使っていた
もの）へは落ちない — 1 台目で育てた値が 2 台目の出発点になってしまうと、
板ごとに分けている意味がなくなるため。まだ値を持たないモニターは上の初期値から
始まる。

## トラブルシュート

exe と同じ場所に `debug.on` という空ファイルを置くと `oscv-debug.log` に
モニター列挙・プローブ・読み書きの結果を記録する。

赤ランプになる主な原因:

- モニターの OSD で DDC/CI が無効になっている
- 別のモニター制御ソフト（OnScreen Control 含む）が同時に DDC を叩いている
- 変換アダプタや KVM が DDC を通さない
