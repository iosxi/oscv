# OSCV

LG モニターの明るさ / コントラスト / ブラックスタビライザーを調整する小さい GUI。

**LG のソフトウェアを一切使わない。** OnScreen Control も osccli も、LG のサービスも不要。
Windows 標準の DDC/CI (`dxva2.dll`) でモニターと直接やり取りする。

- ウィンドウ 280 x 239 (論理px)、実行ファイル 26KB、依存なし (.NET Framework 4)
- マウスのみで操作。キーボード入力なし、確認ダイアログなし
- **ドラッグに画面がリアルタイム追従する**（1 回の書き込みが約 60ms）

## 使い方

`Oscv.exe` を実行するだけ。ショートカットを作ってタスクバーに置くと楽。

| 操作 | 動作 |
|---|---|
| スライダーの上でホイール | 1 ずつ増減。**クリック不要・フォーカス不要**（ホバーだけ） |
| スライダーをドラッグ | 画面がその場で追従。トラックをクリックするとそこへ直行 |
| 弱 / 中 / 強 を左クリック | 3 要素をまとめて適用 |
| 弱 / 中 / 強 を**右クリック** | 現在値をそのプリセットに上書き保存 |
| ヘッダーをドラッグ | ウィンドウ移動（位置は記憶） |
| ◆ / ◇ | 最前面固定のオン/オフ |

ヘッダー左の点＝状態: 緑=正常 / 橙=初期化中 / 赤=エラー。
ウィンドウを前面に出すたびに実値を読み直すので、モニター本体のボタンで変更しても追従する。

## 誤操作対策

- スライダーはトラック中心 ±13px の帯だけが反応する。行の余白を触っても何も起きない
- ホイールはホバーだけで効くので、値を変えるのにクリックが要らない
- トラッククリックは「その位置へ直行」。標準 TrackBar のような予測しづらいページジャンプはしない

## モニター側の仕様（実測）

LG UN700 (LG HDR 4K) で確認した VCP コード:

| 項目 | VCP | write | read |
|---|---|---|---|
| 明るさ | `0x10` | 0〜100 | そのまま |
| コントラスト | `0x12` | 0〜100 | そのまま |
| ブラックスタビライザー | `0xF9` | **0〜20** | **write 値 x 5** |

`0xF9` は LG 固有コード。**write と read でスケールが違う**（`write 16` → `read 80`）。
GUI は 0〜20 に統一して表示している（元のサンプルバッチと同じ目盛り）。

osccli もこの VCP をそのまま中継していただけで、独自仕様ではなかった。

### 実装上の落とし穴

- **`SetVCPFeature` は範囲外の値でも true を返して黙って無視される。**
  `0xF9` に 25 や 90 を書いても何も起きない。呼ぶ前に必ず clamp すること
- **物理モニターのハンドルは 0 が正当な値。** `IntPtr.Zero` を「未オープン」の
  目印に使うと、正常なハンドルを未初期化と誤判定する。専用の bool を持つこと
- **`PHYSICAL_MONITOR` は非 blittable**（string を含む）。配列を
  `[Out] PHYSICAL_MONITOR[]` で受けるとハンドルが正しく返らなかったため、
  `AllocHGlobal` + `PtrToStructure` で手動マーシャリングしている
- **読み取りは約 2.5%（1/40）の確率で一時的に失敗する。** 40ms 間隔でリトライすれば実質 0
- **DDC は I2C シリアルバスなので同時アクセスに弱い。** 別プロセスが同じモニターを
  叩いていると読み書きが失敗する。OnScreen Control を常駐させない方が安定する

## 速度

| | osccli 経由（旧） | DDC 直接（現） |
|---|---|---|
| 値の書き込み | 3500 ms | **約 60 ms** |
| 値の読み取り | 3500 ms | 約 60 ms |
| 起動〜実値表示 | 約 7〜17 秒 | **約 250 ms** |

旧版にあった「ドラッグ中は送らない」「デバウンス」「OSC 自動起動・復旧」は
すべて 3.5 秒への対処だったので、まるごと不要になった。

## 設定ファイル

`oscv.ini`（exe と同じ場所。書き込めなければ `%APPDATA%\oscv\`）にウィンドウ位置・最前面・
最終値・プリセットを保存。プリセット初期値は元のサンプルバッチと同じ:

| | 明るさ | コントラスト | ブラックスタビライザー |
|---|---|---|---|
| 弱 | 30 | 10 | 20 |
| 中 | 40 | 40 | 16 |
| 強 | 65 | 75 | 13 |

## トラブルシュート

exe と同じ場所に `debug.on` という空ファイルを置くと `oscv-debug.log` に
モニター列挙・プローブ・読み書きの結果を記録する。原因が分からないときに使う。

赤ランプになる主な原因:

- モニターの OSD で DDC/CI が無効になっている
- 別のモニター制御ソフト（OnScreen Control 含む）が同時に DDC を叩いている
- 変換アダプタや KVM が DDC を通さない

## ビルド

```
build.bat
```

.NET SDK 不要。Windows 同梱の `csc.exe`（.NET Framework 4）だけでビルドできる。
ソースは [src/Oscv.cs](src/Oscv.cs) 1 ファイル。
